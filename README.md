# Wh40k-EJAJ

Projekt do analizowania zasad i rozpisek do Warhammera 40 000: podręczników, FAQ, errat, pakietów turniejowych i list armii.

## Źródła

- Misje primary i secondary: https://gdmissions.app/11th
- Aktualne pliki do pobrania: https://www.warhammer-community.com/en-gb/downloads/warhammer-40000/
- Munitorum Field Manual — Aeldari: https://mfm.warhammer-community.com/en/aeldari
- Munitorum Field Manual — Necrons: https://mfm.warhammer-community.com/en/necrons

## Zakres

- Legalność rozpiski: punkty, wielkość oddziału, wargear, detachment i ograniczenia armii.
- Zasady na stole: zasięgi, synergie i słabe punkty listy.
- Model i zasada: baza, wysokość, widoczność, loadout i czytelność ekwipunku (WYSIWYG).
